# Python 3.11+ required. Tested on 3.13.
#
# Lower bounds only: the analysis does not depend on behaviour that changed in
# any recent release, and pinning exactly would make the repo harder, not
# easier, for a reviewer to run. `requirements.lock.txt` carries the exact
# versions the Rotterdam baseline was produced with (pip freeze, Python 3.13).
#
# Every package here is imported by src/ or tests/. Nine packages that the
# pipeline never imported were removed -- rasterio, momepy, libpysal, esda,
# scipy, mapclassify, matplotlib, contextily and tqdm. They had been added in
# anticipation of features (raster greenness, street morphometrics, Moran's I /
# LISA, static figures) that do not exist. `esda` even carried a comment
# describing clustering diagnostics that were never written. A dependency list
# that promises capabilities the code does not have is the same
# documentation-versus-reality problem the README had; they go back in when the
# features that need them land.
