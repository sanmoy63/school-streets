# Python 3.11+ required. Tested on 3.13.
#
# Lower bounds only: the analysis does not depend on behaviour that changed in
# any recent release, and pinning exactly would make the repo harder, not
# easier, for a reviewer to run. `requirements.lock.txt` carries the exact
# versions the Rotterdam baseline was produced with (pip freeze, Python 3.13).
#
# Every package here is either imported by src/ or tests/, or is a runtime
# dependency that pip will not resolve on its own -- see scipy below, which is
# the one case where "nothing imports it" was the wrong test.
#
# Removed as genuinely unused: momepy, libpysal, esda, mapclassify, matplotlib,
# contextily, tqdm. Those had been added in anticipation of features -- raster
# greenness, street morphometrics, Moran's I / LISA, static figures -- that do
# not exist; `esda` even carried a comment describing clustering diagnostics
# never written. A dependency list advertising capabilities the code lacks is
# the same documentation-versus-reality problem the README had. They return when
# the features needing them land.
#
# Two came back. rasterio and requests arrived with the population module and
# are imported directly. scipy is the interesting one: nothing imports it, no
# upstream package declares it, and removing it still broke every clean install.
# "Grep for imports" is a necessary test of whether a dependency is needed, not
# a sufficient one.

# --- core geospatial -------------------------------------------------------
geopandas>=1.0
shapely>=2.0
pyogrio>=0.9          # geopandas IO engine; pinned because GPKG round-trips depend on it
pyproj>=3.6           # CRS handling; also imported directly by tests/test_config.py

# --- raster ----------------------------------------------------------------
rasterio>=1.3         # GHS-POP zonal statistics (src/routes_ssr/population.py)
requests>=2.31        # GHS-POP tile download

# --- networks --------------------------------------------------------------
osmnx>=2.0            # NOTE: v2 renamed several functions; v1.x will not work
networkx>=3.2
scipy>=1.11           # REQUIRED, though nothing here imports it: osmnx uses a
                      # scipy KD-tree in nearest_nodes() for *projected* graphs,
                      # which is every graph in this project. It is an optional
                      # dependency of osmnx, so pip will not pull it in, and
                      # removing it fails only on a clean install -- which is
                      # how CI caught it.

# --- visualisation ---------------------------------------------------------
folium>=0.16
branca>=0.7           # colour ramps for the folium map

# --- plumbing --------------------------------------------------------------
pandas>=2.2
numpy>=1.26
pyyaml>=6.0
